# Architecture Decision Records

Eine Datei pro Entscheidung, fortlaufend nummeriert: `0001-partner-dashboard-app.md`, `0002-render-hosting.md`, …

**Regeln**
- Ein ADR wird nie nachträglich geändert. Wird eine Entscheidung revidiert, entsteht ein neues ADR, das alte bekommt `Status: ersetzt durch ADR-XXXX`.
- `plan.md` §1 ist der aktuelle Stand, die ADRs sind die Historie. Beides zu pflegen ist gewollt.
- Kurz. Wer den Kontext in fünf Zeilen nicht erklären kann, hat die Entscheidung nicht verstanden.
- Claude Code legt ADRs an: in WP0 für alle Entscheidungen aus `plan.md` §1, danach für jede Entscheidung, die im Verlauf eines WP getroffen oder revidiert wird.

**Format**: siehe `0000-template.md`.
